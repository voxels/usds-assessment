# Government Regulatory Analyzer

## 🏛️ Executive Summary

The **Government Regulatory Analyzer** is a modern digital tool designed to help policy makers, agency leaders, and the public navigate the complex landscape of federal regulations.

By combining real-time data from **eCFR.gov** with advanced **Google Gemini AI**, this application transforms thousands of pages of legal text into:
-   **Instant Summaries**: Understand what an agency does and how its regulations have changed since 2023.
-   **Activity Timelines**: Visualize which agencies are most active and when.
-   **Impact Analysis**: Detect "Regulatory Footprint" (complexity) and recent amendments.

---

## 📖 User Guide

### 1. Dashboard
The heartbeat of the application.
-   **Global Overview**: Shows how many of the 450+ federal agencies have been analyzed by AI and visualizes regulatory volume.
-   **Department View**: Select a department to see a dedicated dashboard aggregating stats, charts, and recent activity for that specific department.
-   **Activity Charts**: Visualizes the volume of regulatory changes over time.

### 2. Agency Deep Dives
Tap on any agency to see a comprehensive report:
-   **Regulatory Footprint**:  Real-time analysis of word count complexity, based on live eCFR text processing (not estimated).
-   **AI Insights**:
    -   *2023 Baseline*: What the agency's regulations looked like before recent changes.
    -   *Changes Since 2023*: A summary of new rules and deletions.
    -   *Recent Highlights*: The latest batch of updates.
-   **Recent Amendments**: A live feed of the last 5 specific changes (with links to eCFR).

### 3. Search & Discovery
-   **Smart Search**: Find agencies by name, abbreviation, or AI-generated tags (e.g., "Health", "Transportation").
-   **Offline Access**: Once synced, the entire database works without an internet connection.

### 4. Security
-   **API Key Protection**: Administrative endpoints (`ingest`, `analyze`, `summarize`) require an `x-api-key` header.
-   **Public Access**: Read-only endpoints (`agencies`, `stats`, `amendments`) remain public for ease of integration.

## 🏗 Technical Architecture

### 📱 iOS Application (Swift 6)
Built with a modern, offline-first architecture focusing on performance and thread safety.

-   **MVVM Pattern**: ViewModels (`AppViewModel`, `AgencyDetailViewModel`) manage state and business logic, isolated to the `@MainActor`.
-   **SwiftData**: Local persistence for 450+ agencies and their summaries.
-   **Actor-Based Sync**: `SyncService` is an `actor` that manages its own `ModelContext`, ensuring thread-safe background synchronization without data races.
-   **Protocol-Oriented**: `DataServiceProtocol` abstracts network calls, enabling seamless extensive unit testing with `MockDataService`.
-   **Optimizations**:
    -   **Batch Saving**: Syncs are committed in batches of 50 to minimize memory footprint.
    -   **Background Processing**: Heavy text processing (Tag Extraction) is offloaded to detached tasks.

### ☁️ Backend (Firebase Cloud Functions)
Node.js environment acting as the intelligence layer.

-   **Service-Oriented**: `EcfrService` (`ecfr.js`) consolidates specific eCFR API logic (search, metadata, content) into a reusable module.
-   **Resilience**: Robust retry logic with exponential backoff handles eCFR API rate limits (429) and downtime (503).
-   **AI Pipelines**:
    -   **Comparative Analysis**: Feeds both historical (2023) and current regulatory text to **Gemini 1.5 Pro** (with Flash fallback) for accurate diff summaries.
    -   **Parallel Processing**: AI summaries are generated in concurrent batches (limit: 5) to optimize throughput.
-   **Endpoints**:
    -   `GET /agencies`: Full dataset sync.
    -   `GET /amendments?agency_slug=...`: Proxies eCFR Search API for recent changes.
    -   `GET /summarize?agency_id=slug`: On-demand AI summary.
    -   `GET /stats`: Aggregated timelines and title distributions.

## 🚦 Getting Started

### Backend Setup
1.  **Install Dependencies**:
    ```bash
    cd functions && npm install
    ```
2.  **Set Secrets**:
    ```bash
    firebase functions:secrets:set GOOGLE_AI_API_KEY
    ```
3.  **Deploy**:
    ```bash
    firebase deploy --only functions
    ```
4.  **Initial Ingest** (Run once to populate DB):
    ```bash
    curl -H "x-api-key: assessment-admin-key" https://api-ylhco6bvia-uc.a.run.app/ingest
    curl -H "x-api-key: assessment-admin-key" https://api-ylhco6bvia-uc.a.run.app/analyze
    ```

### iOS Setup
1.  Open `usdsassessment.xcodeproj` in **Xcode 16+**.
2.  Ensure **Signing & Capabilities** are set to your team.
3.  Build and Run (⌘R) on iPhone 15/16 Simulator or Device.
